Playerok Assistant v1.3.3
=========================
Инструкция по использованию

------------------------------
1. УСТАНОВКА И ЗАПУСК
------------------------------
1. Распакуйте архив в любую папку (например, C:\PlayerokAssistant).
2. Запустите файл PlayerokAssistant.exe.

   ВАЖНО:
   - Не удаляйте папку _internal рядом с PlayerokAssistant.exe —
     без неё программа не запустится.
   - Программа требует подключение к интернету при каждом запуске:
     она проверяет ключ активации на сервере. Без интернета запуск
     невозможен.
   - Процесс PlayerokAssistant должен оставаться в Рабочем столе/трее.

------------------------------
2. АКТИВАЦИЯ
------------------------------
Имя пользователя телеграмм бота приложения: @Playerokk_auto_bot
При первом запуске программа попросит ключ активации:
1. Получите ключ у продавца (выдаётся после оплаты).
2. Введите ключ в поле активации и нажмите «Активировать».
3. Подождите проверки ключа (1–3 секунды).

Дополнительно:
- Один ключ привязан к одному компьютеру и не может быть использован
  на другом одновременно.
- Кнопка «Деактивировать» в окне активации позволяет перенести ключ
  на другой компьютер.

------------------------------
3. НАСТРОЙКА АККАУНТА
------------------------------
Откройте раздел «Настройки» -> вкладка «Аккаунты».

Обязательные поля (подсвечены красным, пока не заполнены):
- Токен аккаунта (token) Playerok.
- User-Agent браузера.

Как получить Токен:
1. Откройте playerok.com и войдите в свой аккаунт.
2. Нажмите F12 (откроются Инструменты разработчика).
3. Вкладка Application (Приложение) -> Cookies (Файлы cookie) ->
   https://playerok.com -> поле token.
4. Скопируйте значение token (длинная строка из букв и цифр)
   и вставьте в поле «Токен аккаунта».

Как получить User-Agent:
1. Там же, в Инструментах разработчика, откройте вкладку Network (Сеть).
2. Обновите страницу (F5).
3. Кликните на любой запрос в списке -> найдите заголовок User-Agent
4. Скопируйте этот заголовок целиком и вставьте в поле «User-Agent браузера».

Внимание! User-Agent и Токен должны быть с одного браузера, в котором вы
залогинились в Playerok. Если использовать чужой или изменённый User-Agent —
Playerok может заблокировать вход.

Несколько аккаунтов:
- Кнопка «Добавить аккаунт» позволяет подключить несколько аккаунтов.
- Одновременно может работать не более 5 аккаунтов.
- Переключайтесь между ними через выпадающий список вверху окна.
- У каждого аккаунта свои Токен, User-Agent и настройки.

------------------------------
4. ЗАПУСК БОТА
------------------------------
1. В разделе «Статистика» (Dashboard) нажмите «Старт» («Start»).
2. Бот подключится к Playerok, загрузит ваш профиль и баланс.
3. Программа начнёт следить за лотами, продажами и отзывами.

Кнопки управления:
- Старт (Start) — запустить бота.
- Стоп (Stop) — остановить бота.
- Обновить (Refresh) — обновить баланс и количество лотов.

Автозапуск бота при старте программы:
- Настройки -> вкладка «Запуск».
- Включите «Автозапуск бота» и, при желании, «Автозапуск при входе в Windows»
  — программа (и бот) запустятся автоматически при включении компьютера.

------------------------------
5. ОСНОВНЫЕ ВОЗМОЖНОСТИ
------------------------------
- Автоматический контроль лотов: мониторинг цен, позиций и наличия на продаже.
- Обработка продаж: контроль сделок и уведомления о новых продажах.
- Отзывы: уведомления о новых отзывах и возможность их отслеживать.
- Премиум-продвижение: автоматическая проверка позиций и включение
  платного продвижения по позиции или по расписанию.
- Автоперевыставление: если Playerok сам не перевыставил проданный лот, бот может
  перевыставить его сам(без премиума).
- Статистика продаж: таблица сделок, экспорт в Excel (раздел «Продажи»).

Настройки премиума (Настройки -> вкладка «Запуск»):
- Режим «По позиции» — проверка позиций выполняется автоматически.
- Режим «По расписанию» — включение продвижения в указанные дни/время.
- Порог позиции для премиума — если лот в выдаче опустился ниже этой
  позиции, бот покупает платное продвижение.
- Дневной лимит премиума — максимальная сумма на премиум в день
  (0 = без лимита).

Интервалы проверок и кулдауны зафиксированы в коде (адаптивные под
нагрузку) — пользователь их изменить не может, это защищает аккаунт
от блокировок за частые запросы.

------------------------------
6. ДАННЫЕ ПРОГРАММЫ
------------------------------
Все данные хранятся в той же папке, где лежит exe:
- configs/ — настройки аккаунтов.
- storage/ — сохранённые данные (статистика, лоты).
- logs/ — журналы работы.

Удаление этих папок сбрасывает настройки программы
(активация ключа при этом сохраняется).

------------------------------
7. ДЕАКТИВАЦИЯ КЛЮЧА
------------------------------
Способ 1 (в программе):
- Настройки -> вкладка «Активация» -> кнопка «Деактивировать».

Способ 2 (через Telegram-бота @Playerokk_auto_bot):
- Отправьте боту команду: /deactivate ВАШ_КЛЮЧ
- Подтвердите кнопкой.

Ограничение: повторная деактивация ключа возможна не чаще одного раза
в 24 часа.

После деактивации ключ можно использовать на другом компьютере.
