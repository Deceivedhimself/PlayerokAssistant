# Playerok Assistant

Автоматизация магазина на Playerok: контроль лотов, продаж, отзывов и продвижения.

## Системные требования

- Windows 10/11 (64-бит)
- Подключение к интернету (обязательно при каждом запуске — проверка ключа активации)

## Установка

1. Скачайте архив: [PlayerokAssistant_v1.3.0_CLEAN.zip](PlayerokAssistant_v1.3.0_CLEAN.zip)
2. Распакуйте архив в любую папку (например, `C:\PlayerokAssistant`).
3. Запустите `PlayerokAssistant.exe`.

> Не удаляйте папку `_internal` рядом с `PlayerokAssistant.exe` — без неё программа не запустится.

## Активация

При первом запуске программа попросит ключ активации:

1. Получите ключ у продавца (выдаётся после оплаты).
2. Введите ключ в поле активации и нажмите **«Активировать»**.
3. Один ключ привязан к одному компьютеру и не может быть использован на другом одновременно.
4. Кнопка **«Деактивировать»** позволяет перенести ключ на другой компьютер (или через Telegram-бота).

Управление ключами и поддержка: [@Playerokk_auto_bot](https://t.me/Playerokk_auto_bot)

## Настройка аккаунта

Откройте **Настройки → Аккаунты**. Обязательные поля (подсвечены красным, пока не заполнены):

- **Токен аккаунта** (token) Playerok.
- **User-Agent браузера**.

### Как получить Токен

1. Откройте [playerok.com](https://playerok.com) и войдите в свой аккаунт.
2. Нажмите **F12** (Инструменты разработчика).
3. Вкладка **Application (Приложение) → Cookies (Файлы cookie) → https://playerok.com → поле `token`**.
4. Скопируйте значение `token` и вставьте в поле «Токен аккаунта».

### Как получить User-Agent

1. Там же, в Инструментах разработчика, откройте вкладку **Network (Сеть)**.
2. Обновите страницу (**F5**).
3. Кликните на любой запрос и в заголовках найдите **User-Agent** (например: `Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/143.0.0.0 Safari/537.36`).
4. Скопируйте этот заголовок целиком и вставьте в поле «User-Agent браузера».

> Токен и User-Agent должны быть из одного браузера, в котором вы залогинены в Playerok. Иначе Playerok может заблокировать вход.

### Несколько аккаунтов

- Кнопка **«Добавить аккаунт»** позволяет подключить несколько аккаунтов.
- Переключайтесь через выпадающий список вверху окна.
- У каждого аккаунта свои Токен, User-Agent и настройки.

## Запуск бота

1. В разделе **«Статистика»** нажмите **«Старт»**.
2. Бот подключится к Playerok, загрузит профиль и баланс и начнёт следить за лотами, продажами и отзывами.

Кнопки: **Старт**, **Стоп**, **Обновить**.

Автозапуск: **Настройки → Запуск** — включите «Автозапуск бота» и «Автозапуск при входе в Windows».

## Возможности

- Контроль лотов: мониторинг цен, позиций и наличия на продаже.
- Продажи: контроль сделок и уведомления о новых продажах.
- Отзывы: уведомления о новых отзывах.
- Продвижение: автоматическая проверка позиций и покупка платного продвижения.
- Статистика продаж с экспортом в Excel.

## Данные программы

Все данные хранятся в той же папке, где лежит exe:
- `configs/` — настройки аккаунтов
- `storage/` — статистика, лоты
- `logs/` — журналы работы

Удаление этих папок сбрасывает настройки (активация ключа сохраняется).

## Деактивация ключа

- В программе: **Настройки → Активация → «Деактивировать»**.
- Через Telegram-бота: `/deactivate ВАШ_КЛЮЧ`.

После деактивации ключ можно использовать на другом компьютере.
