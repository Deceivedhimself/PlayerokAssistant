# Playerok Assistant

## О приложении

**Playerok Assistant** — программа-ассистент для автоматизации магазина на
[Playerok.com](https://playerok.com). Она сама следит за вашими лотами:
контролирует их позиции, цены и наличие на продаже, обрабатывает продажи и
отзывы, покупает платное продвижение и перевыставляет проданные товары — чтобы
вы тратили меньше времени на рутину и больше зарабатывали.

### Плюсы приложения

- **Работает без вашего участия.** Бот сам отслеживает лоты, продажи и отзывы:
  достаточно открыть программу и нажать «Запустить»(по умолчанию в боте включена функция с загрузкой аккаунтов, поэтому нажимать «Запустить» не обязательно).
- **Экономит на премиуме.** Платное продвижение включается автоматически, только
  когда это действительно нужно: по позиции (лот опустился ниже выбранного
  порога) или по расписанию, с дневным лимитом расходов.
- **Защищает аккаунт от блокировки.** Запросы к Playerok выполняются с
  безопасными паузами, рассчитанными под лимиты площадки, — приложение не
  создаёт лишней нагрузки и не провоцирует блокировку аккаунта из-за частых
  обращений.
- **До 5 аккаунтов одновременно.** Можно подключить несколько магазинов и
  управлять ими из одного окна, переключаясь между аккаунтами в пару кликов.
- **Автоперевыставление проданных лотов.** Если Playerok не перевыставил проданный
  лот сам, бот перевыставит его без премиума.
- **Авто-подтверждение сделок.** Подходящие сделки отмечаются как «товар
  отправлен» без лишних кликов — настройка включается отдельно для каждого лота.
- **Всегда знает позицию лота.** Бот проверяет позицию не только вверху выдачи,
  но и глубоко по ней: даже если лот упал далеко за порог, вы точно знаете, где
  он находится (отчёт вида «позиция 850\800»).
- **Всё в одном окне.** Баланс, количество лотов, события, ленты лотов по статусам
  (в продаже, на проверке, заблокированные, проданные, истёкшие, черновики),
  статистика продаж и экспорт в Excel.
- **Настройки не теряются.** Приложение хранит резервную копию настроек и
  автоматически восстанавливает их после сбоя файла —
  ваши лоты, аккаунты и настройки не сбрасываются.
- **Полная автоматизация — даже когда ПК выключен.** Приложение запускается
  автоматически при входе в систему («Автозапуск при входе в Windows» в
  Настройках → Запуск). Дополнительно вы сами можете настроить включение
  компьютера по расписанию в BIOS/UEFI (это функция материнской платы,
  настраивается вне приложения): ПК сам включится в нужное время, а вместе с ним
  автоматически запустится и бот. Например, если ПК включается в 7:00, к вашему
  пробуждению лоты уже будут проверены.
- **Данные только на вашем компьютере.** Пароли и настройки хранятся локально в
  папке программы — ничего не уходит на сторонние серверы.

## Инструкция по использованию

### УСТАНОВКА И ЗАПУСК

1. Распакуйте архив в любую папку (например, C:\PlayerokAssistant).
2. Запустите файл PlayerokAssistant.exe.

ВАЖНО:

- Не удаляйте папку _internal рядом с PlayerokAssistant.exe — без неё программа
  не запустится.
- Программа требует подключение к интернету при каждом запуске: она проверяет
  ключ активации на сервере. Без интернета запуск невозможен.
- Процесс PlayerokAssistant должен оставаться в Рабочем столе/трее.

### АКТИВАЦИЯ

Имя пользователя Telegram-бота приложения: **@Playerokk_auto_bot**

При первом запуске программа попросит ключ активации:

1. Получите ключ у продавца (выдаётся после оплаты).
2. Введите ключ в поле активации и нажмите «Активировать».
3. Подождите проверки ключа (1–3 секунды).

Дополнительно:

- Один ключ привязан к одному компьютеру и не может быть использован на другом
  одновременно.
- Кнопка «Деактивировать» в окне активации позволяет перенести ключ на другой
  компьютер.

### НАСТРОЙКА АККАУНТА

Откройте раздел «Настройки» → вкладка «Аккаунты».

Обязательные поля (подсвечены красным, пока не заполнены):

- Токен аккаунта (token) Playerok.
- User-Agent браузера.

**Как получить Токен:**

1. Откройте playerok.com и войдите в свой аккаунт.
2. Нажмите F12 (откроются Инструменты разработчика).
3. Вкладка Application (Приложение) → Cookies (Файлы cookie) →
   https://playerok.com → поле token.
4. Скопируйте значение token (длинная строка из букв и цифр) и вставьте в поле
   «Токен аккаунта».

**Как получить User-Agent:**

1. Там же, в Инструментах разработчика, откройте вкладку Network (Сеть).
2. Обновите страницу (F5).
3. Кликните на любой запрос в списке → найдите заголовок User-Agent.
4. Скопируйте этот заголовок целиком и вставьте в поле «User-Agent браузера».

Внимание! User-Agent и Токен должны быть с одного браузера, в котором вы
залогинились в Playerok. Если использовать чужой или изменённый User-Agent —
Playerok может заблокировать вход.

**Несколько аккаунтов:**

- Кнопка «Добавить аккаунт» позволяет подключить несколько аккаунтов.
- Одновременно может работать не более 5 аккаунтов.
- Переключайтесь между ними через выпадающий список вверху окна.
- У каждого аккаунта свои Токен, User-Agent и настройки.

### ЗАПУСК БОТА

1. В разделе «Статистика» (Dashboard) нажмите «Старт» («Start»).
2. Бот подключится к Playerok, загрузит ваш профиль и баланс.
3. Программа начнёт следить за лотами, продажами и отзывами.

Кнопки управления:

- Старт (Start) — запустить бота.
- Стоп (Stop) — остановить бота.
- Обновить (Refresh) — обновить баланс и количество лотов.

**Автозапуск бота при старте программы:**

- Настройки → вкладка «Запуск».
- Включите «Автозапуск бота» и, при желании, «Автозапуск при входе в Windows» —
  программа (и бот) запустятся автоматически при включении компьютера.

### ОСНОВНЫЕ ВОЗМОЖНОСТИ

- Автоматический контроль лотов: мониторинг цен, позиций и наличия на продаже.
- Обработка продаж: контроль сделок и уведомления о новых продажах.
- Отзывы: уведомления о новых отзывах и возможность их отслеживать.
- Премиум-продвижение: автоматическая проверка позиций и включение платного
  продвижения по позиции или по расписанию.
- Автоперевыставление: если Playerok сам не перевыставил проданный лот, бот
  может перевыставить его сам (без премиума).
- Статистика продаж: таблица сделок, экспорт в Excel (раздел «Продажи»).

**Настройки премиума (Настройки → вкладка «Запуск»):**

- Режим «По позиции» — проверка позиций выполняется автоматически.
- Режим «По расписанию» — включение продвижения в указанные дни/время.
- Порог позиции для премиума — если лот в выдаче опустился ниже этой позиции,
  бот покупает платное продвижение.
- Дневной лимит премиума — максимальная сумма на премиум в день (0 = без
  лимита).

Интервалы проверок и кулдауны настроены в коде с запасом под нагрузку —
пользователь их изменить не может, это защищает аккаунт от блокировок за частые
запросы.

### ДАННЫЕ ПРОГРАММЫ

Все данные хранятся в той же папке, где лежит exe:

- configs/ — настройки аккаунтов.
- storage/ — сохранённые данные (статистика, лоты).
- logs/ — журналы работы.

Удаление этих папок сбрасывает настройки программы (активация ключа при этом
сохраняется).

### ДЕАКТИВАЦИЯ КЛЮЧА

**Способ 1 (в программе):**

- Настройки → вкладка «Активация» → кнопка «Деактивировать».

**Способ 2 (через Telegram-бота @Playerokk_auto_bot):**

- Отправьте боту команду: /deactivate ВАШ_КЛЮЧ
- Подтвердите кнопкой.

Ограничение: повторная деактивация ключа возможна не чаще одного раза в 24 часа.

После деактивации ключ можно использовать на другом компьютере.
